C-CDA R2.1 Document Generator

Generates a valid Continuity of Care Document (CCD) conforming to C-CDA R2.1 (HL7 templateId 2.16.840.1.113883.10.20.22.1.2.1). Patient demographics are pulled from the database; encounter/diagnosis data is enriched from any linked SFTP clinical records.

HL7 C-CDA R2.1
Pipeline: PatientRecord (DB) + ClinicalRecord (DB) → C-CDA XML generator → Sections: Allergies · Problem List · Encounters  ·  Endpoint: POST /api/ccda/generate/
Generate Document POST /api/ccda/generate/
C-CDA R2.1 Structure

Document Header

  • realmCode · typeId · templateId (CDA R2 + C-CDA R2.1)
  • id (UUID) · code (LOINC 34133-9) · title
  • effectiveTime · confidentialityCode
  • recordTarget → patientRole → patient
  • author → assignedAuthoringDevice
  • custodian → representedCustodianOrganization

Structured Body Sections

  • AllergiesLOINC 48765-2 (no known allergies entry)
  • ProblemsLOINC 11450-4 — ICD-10 observations from encounters
  • EncountersLOINC 46240-8 — visit dates, types, procedures
