DFT^P03 messages carry itemised charge data (FT1 segments) from the clinical system to the billing engine. Each ADT A01/A03 event automatically generates a DFT^P03 with procedure-specific charge lines, which are then mapped to an X12 837P professional claim.

Flat File

SFTP Flat-File Ingestion

Simulates an sFTP polling job that picks up CSV, pipe-delimited, or tab-delimited drops. The parser auto-detects delimiter and schema, validates every row with field-level rules (ICD-10 regex, CPT/HCPCS, required fields, date formats), and persists clean records to PostgreSQL. Supports two schemas: PATIENT demographics (upsert to PatientRecord) and CLINICAL encounters.

Specification
DelimitersComma (CSV), Pipe |, Tab \t
EncodingUTF-8-BOM · UTF-8 · Latin-1
Max file size20 MB
Max rows50,000
Upload endpointPOST /api/sftp/upload/
Run listGET /api/sftp/runs/
UISFTP Ingest →

Observability

End-to-End Tracing & Audit Log

Every inbound message is assigned a trace_id (UUID) and passes through a multi-step pipeline tracked in TraceLog / TraceStep. Each step records status, latency, and error detail. The Data Quality Monitor surfaces aggregate metrics, flags incomplete or delayed messages, and auto-refreshes every 30 seconds.
