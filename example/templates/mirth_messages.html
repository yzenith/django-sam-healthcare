In production, Mirth Connect channels handle HL7 ingestion, routing, and transformation. Each channel has a Source Connector (TCP/MLLP listener), a Transformer (JavaScript), and one or more Destination Connectors (REST, DB write, file). Below is the JS transformer that mirrors what this Django API performs server-side.

Mirth JS Transformer — HL7_Inbound_ADT / Source

// ── Mirth Connect JavaScript Transformer ──────────────────────────
// Channel: HL7_Inbound_ADT  |  Scope: Source  |  Mirth 4.x

// 1. Parse key fields (Mirth auto-parses HL7 into msg object)
var msgType    = msg['MSH']['MSH.9']['MSH.9.1'].toString();  // e.g. "ADT"
var trigEvent  = msg['MSH']['MSH.9']['MSH.9.2'].toString();  // e.g. "A01"
var sendingApp = msg['MSH']['MSH.3'].toString();
var patientId  = msg['PID']['PID.3']['PID.3.1'].toString();  // MRN
var lastName   = msg['PID']['PID.5']['PID.5.1'].toString();
var firstName  = msg['PID']['PID.5']['PID.5.2'].toString();
var dob        = msg['PID']['PID.7'].toString();             // YYYYMMDD
var gender     = msg['PID']['PID.8'].toString();             // M/F/U

// 2. Route A01/A03 to billing pipeline
if (trigEvent == 'A01' || trigEvent == 'A03') {
  channelMap.put('routeToBilling', 'true');
}

// 3. Build JSON payload for REST destination connector
var payload = {
  message_type: msgType + '^' + trigEvent,
  patient_id:   patientId,
  raw_hl7:      connectorMessage.getRawData(),
  sending_app:  sendingApp
};
channelMap.put('jsonPayload', JSON.stringify(payload));

// 4. Validate required fields; flag for destination filter
if (!patientId) {
  channelMap.put('validationError', 'Missing PID-3 (MRN)');
  channelMap.put('processingStatus', 'FAILED');
} else {
  channelMap.put('validationError', '');
  channelMap.put('processingStatus', 'VALIDATED');
}

// 5. Set ACK code (AA = accept, AE = error)
channelMap.put('ackCode', channelMap.get('validationError') ? 'AE' : 'AA');

In this demo the same logic runs server-side in example/hl7_utils.py + MirthHL7View. The channelMap values above flow into the REST Destination Connector body template as ${jsonPayload}.
