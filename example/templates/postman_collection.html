Quick Start
  1. Click Download JSON above.
  2. In Postman: File → Import and select the downloaded file.
  3. Set the base_url collection variable to your server (default: http://127.0.0.1:8000).
  4. Run Auth & Setup → Login (session) first — this seeds your session cookie.
  5. Run the full collection with the Collection Runner to see all tests pass.

Pre-request Scripts
PKCE (Authorization Code flow)

The Authorize (consent page) request auto-generates a PKCE pair using CryptoJS and stores code_verifier + code_challenge as collection variables. The Token exchange request reads them automatically. 

const verifier = CryptoJS.lib.WordArray.random(32).toString(CryptoJS.enc.Base64url);
const hash = CryptoJS.SHA256(verifier);
const challenge = hash.toString(CryptoJS.enc.Base64url).replace(/=+$/, "");
pm.collectionVariables.set("code_verifier", verifier);
pm.collectionVariables.set("code_challenge", challenge);
Mirth JWT

The Mirth HL7 ingest request builds an HS256 JWT signed with mirth_secret (iss=django-sam-healthcare, aud=mirth-connector, 5-minute TTL).

Test coverage: Every request includes pm.test() assertions (status codes, JSON schema, FHIR resourceType, OAuth field presence, NDJSON content-type). Negative cases verify proper 4xx responses for invalid PKCE verifiers, unsupported grant types, invalid bulk _outputFormat, and duplicate client registrations.
