How this works: After each successful HL7 → FHIR transform, dispatch_webhooks_for_result() is called. It creates a WebhookDelivery record per FHIR resource and simulates an HTTP POST to the target system. In production, this would use a task queue (Celery/SQS) so delivery failures never block the inbound pipeline. The 80% success rate here demonstrates what a failure dashboard looks like — ops teams use this view to identify stuck deliveries and trigger retries.
